# 08 — Cursor Experience Stations (Expo Concept)

> Instead of partner booths, make them **Cursor Experience Stations**. Each showcases one core
> capability with a **5-minute challenge**. People collect **stamps** and earn merch/credits after
> completing them. This turns a meetup into an **expo**.

## The stations (feature-named)

1. **Prompt Like a Pro** — *Agent Mode.* Build a weather app using only prompts, no manual coding.
   Teaches prompting, planning, iterating with Agent.

2. **Background Agents Lab** — *Background Agents.* Theme: *"Hire your first AI engineer."*
   Give Cursor a feature request → walk away → visit other stations → come back to **review the PR**.

3. **BugBot Rescue Center** — *BugBot.* Give attendees a repo with hidden bugs → run BugBot →
   count issues caught. Extra: fix every BugBot comment in under 5 minutes.

4. **MCP Marketplace** — *One-Click MCP.* Several laptops, each with one MCP (GitHub, Slack, Figma,
   Playwright, Notion). Install one with a single click and ask Cursor to use it.

5. **Memory Challenge** — *Memories.* Teach Cursor your coding preferences → start a fresh task →
   watch it remember your conventions automatically.

6. **Tab Speed Race** — *Tab Model.* Leaderboard: who completes a feature fastest using only Tab
   completions? No typing except accepting suggestions.

7. **Multi-Agent Arena** — *Cloud Subagents.* Launch three agents at once: one fixes tests, one writes
   docs, one builds auth. Show parallel work.

8. **Rules Workshop** — *.cursor/rules.* Turn a messy repo into one where Cursor follows company
   conventions automatically. Show before / after.

9. **Jupyter AI Lab** — *Notebook Support.* Analyze a dataset → generate charts → explain findings,
   all inside Cursor. (Big for India's AI/ML crowd.)

10. **AI Automation Station** — *Cursor Automations.* Describe a workflow in plain English
    (*"When a PR opens, review it, fix lint, create a summary"*) → Cursor builds the automation.

## Cooler naming (make them attractions, not features)

- 🚀 **AI Engineer Hiring Booth** (Background Agents)
- 🐞 **Bug Hospital** (BugBot)
- 🧠 **Memory Vault**
- 🔌 **MCP Portal**
- ⚡ **Speed Coding Arena** (Tab)
- 🤖 **Agent Mission Control** (Multi-agent)
- 📓 **Data Science Lab** (Jupyter)
- 🏁 **Ship It Challenge**
- 🛠 **Prompt Engineering Garage** (Agent Mode)
- ☁ **Cloud Coding Zone**

## My favorite

**Background Agents Lab.** Someone starts a task when they arrive, spends an hour exploring the
event, comes back to find their feature implemented and ready to review. It's the single most
memorable demonstration of what makes Cursor different from a traditional AI coding assistant.
