# 02 — Demo Playbook (Stage / Meetup)

> Rule #1: **Don't** demo "write a React button." Everyone's seen it.
> Show **agentic workflows** that make people go *"wait… it can do that?"*

## The 10 demos

### 1. Background Agent (10/10 demo — Cursor's biggest feature)
Prompt: *"Build a dashboard with authentication using Next.js and Supabase."*
- Launch a **Background Agent** instead of blocking the editor.
- Keep coding locally; open the cloud agent.
- Watch it clone the repo → commits happen → open the generated PR.
- Line: *"It's like having another engineer working beside you."* → huge reaction.

### 2. BugBot
Most people don't know Cursor reviews code automatically.
- Push a PR → BugBot comments → click **Fix in Cursor** → Cursor already knows the context.
- Line: *"Instead of reading comments and figuring out context, Cursor opens directly where the fix belongs."*

### 3. MCP in 30 seconds
Kill the myth that MCP is complicated.
- Show the marketplace: GitHub, Notion, Figma, Slack, Playwright.
- Install one with **one click** (OAuth supported).
- Line: *"Five months ago this took config files and env vars. Now it's one click."*

### 4. Memories (underrated)
Teach it: *Always use Tailwind. Never semicolons. Prefer Zustand. Use shadcn.*
- Later: *"Create a new page."* → Cursor **remembers** the preferences automatically.

### 5. Jupyter Notebook support (big for India — AI/ML students)
Open a notebook, ask Cursor to: clean a dataset → visualize it → train an XGBoost model →
explain why accuracy dropped. It **edits multiple notebook cells directly**.

### 6. Rich Chat
Prompt: *"Design a microservices architecture for Uber."* → Mermaid/architecture diagrams,
markdown tables appear **inside chat**.

### 7. Agent vs Chat (my favorite framing)
- Normal AI: *"Build authentication."*
- Agent: add auth → create middleware → update docs → create tests → run lint → fix errors → commit.
- People instantly get **why Cursor feels different**.

### 8. Automations (newest — team will be excited about this)
Always-on automations. Example: *"When someone opens a GitHub issue → categorize → label →
create a fix → open a PR → notify Slack."* Or: *"React 🤖 in Slack → fix issue → open PR → post summary."*
Create them in **plain English** via `/automate`.

### 9. Computer Use
Cloud agents can actually use a computer: *"Deploy my app → open Chrome → verify login →
take screenshots → generate a demo GIF."* Feels futuristic live.

### 10. Full software engineer workflow (keynote closer)
*"Implement dark mode → update docs → run tests → fix failures → commit → open PR → review PR →
fix review comments."*
- Story: Background Agent writes → BugBot reviews → Cursor fixes the review → all in one workflow.
- Message: **from AI-assisted coding → autonomous software engineering.**
