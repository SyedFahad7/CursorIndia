# 04 — Roadshow Learnings (What to Steal)

References: **Hack This Fall (HTF)**, **MLH AI Roadshow**, **FOSS United SEGFAULT**,
**Google Developer Events**, **JunctionX**.

## Hack This Fall — the best Indian reference

They don't organize events; they create a **journey** people keep talking about.

1. **A "tour," not isolated meetups**
   HTF ran **Build Stations** across Mumbai, Ahmedabad, Delhi NCR, Kolkata, Hyderabad → all leading
   to one bigger **finale in Bengaluru**. Every city felt like part of one nationwide experience.
   → **Cursor version:** brand it *"Cursor India Tour"* — same branding, hashtags, merch style,
   agenda, and photography style across cities. *"Cursor is touring India."*

2. **Build Stations (biggest idea to steal)**
   Not everyone crammed into one hackathon venue — *"come continue building with mentors"*
   (workshops + hacking + mentorship + networking together).
   → **Cursor Build Station:** bring your laptop + side project; Cursor engineers walk around helping.
   *"Show us your repo"* → 5 min later a Background Agent fixed half your bugs. Way better than slides.

3. **Invite-only / application-based** → instantly raises perceived value.
   → Cursor doesn't need to reject many, but *"Apply → selected builders get exclusive merch,
   reserved seating, networking session."* People value exclusivity.

4. **Community-first identity**
   HTF markets *builders / creators / hackers / innovators*, not "our hackathon."
   → *"India's AI Builders Tour, powered by Cursor"* > *"Cursor Meetup."*

5. **Hacker House finale**
   HTF ends with a Hacker House where top builders meet mentors before Demo Day.
   → Invite ~20 founders + 20 OSS maintainers + 20 top ambassadors → private dinner with Cursor
   engineers, no livestream, just conversations → long-term advocates.

6. **Many sponsors / booths**
   HTF has GitHub, Vonage, Orkes, MLH, CodeRabbit, Apify, ETHIndia, etc. interacting via booths/workshops/swag.
   → Cursor could partner with ecosystem companies: Supabase, Vercel, Neon, Clerk, Graphite, Exa, Tavily, Mem0.
   Each gets a small demo station → attendees explore instead of sitting through talks.

7. **Activity passports** — always multiple things happening (booths, mini-challenges, interviews,
   workshops, swag hunts) → people stay busy.
   → Passport: MCP booth ✅ Agent demo ✅ Memories ✅ Background Agent ✅ BugBot ✅ → complete all → exclusive merch.

8. **Interview attendees** — HTF constantly films testimonials.
   → *"What's the coolest thing you've built with Cursor?"* → LinkedIn posts, IG reels, X clips, Shorts.
   More authentic than polished ads.

9. **Community challenges** — social contests, mascot contests, sponsor activities throughout.
   → *"Build something in 1 hour with Cursor Agent"* → top 10 → audience votes → merch + credits + feature on socials.

10. **Swag should be earned** — people remember *how* they earned swag (testimonials, activities, prizes).
    → Don't hand totes at registration. Earn via: hidden QR, demo trail, build a project, trivia, share a post, complete passport.

## Original idea that fits Cursor perfectly

**Cursor Repo Doctor** — devs register beforehand + submit GitHub repos. Team picks ~10.
Live on stage: open repo → run Cursor Agent → fix bugs → refactor → improve perf → commit.
Audience watches **real engineering** (not toy demos). Everyone thinks *"next time maybe my repo."*

## MLH AI Roadshow (my own reference)

There **wasn't a hackathon at every city** — cities acted as **activation events** (talks, demos,
networking, interactive stations). An **async Cursor Buildathon** can play the same role alongside the roadshow.
(BLR stop reference: majorleaguehacking.smugmug.com/MLH-AI-Roadshow/BLR-MLH-AI-Roadshow)

## FOSS United SEGFAULT — closest to our online+offline model

Recommends a **hybrid format**: online build phase → mentored check-ins → in-person finals/showcase.
They state hybrid **outperforms** purely online or purely onsite hackathons.

## Google Developer Events

Combines online AI challenges/competitions with local *Build with AI / I/O Connect / GDG* events.
Not one roadshow, but the ecosystem is designed similarly.

## JunctionX

One global hackathon **brand**; local cities host their own events under the same umbrella →
cities feed one larger program instead of feeling isolated.

## The pitch framing

- The **online Buildathon = the campaign** (the umbrella everyone joins).
- The **roadshow = the activation** (in-person energy in each city).
- Every city promotes the same Buildathon; people keep working after the meetup; a final online
  **demo day** announces winners → **one nationwide experience**, not five disconnected events.
